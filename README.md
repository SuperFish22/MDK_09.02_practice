# УП.09.02 Оптимизация веб-приложений

Учебный сайт практики: 6 тем с разбором, инфографикой, видео, полезными ссылками, тестами для самопроверки и практическими работами.

## Структура
- `index.html` — главная: темы, расписание, практические работы
- `tema-*.html` — страницы тем
- `assets/` — стили и скрипт тестов
- `PPTX/` — презентации к темам (.pptx)
- `practice/` — задания практических работ и шаблон итогового отчёта (.docx)

Чтобы заменить задание, положите новый файл в `practice/` с тем же именем.
